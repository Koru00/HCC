# Testing

## Test project

`HolyTest` is a C++ console application with a small registration-based test harness. Tests use `TEST(name)` to register a function and `CHECK(expression)` to record a failed check. The runner prints each selected test's status and returns a nonzero exit code if any check fails.

The current test sources focus on `HolyCore`: arena allocation, hash maps, platform behavior, source management, string interning, and vectors.

## Run tests

Build the `HolyTest` project in Visual Studio, then run the produced executable. With no argument, it runs all registered tests. One optional argument is treated as a case-sensitive substring filter against test names. For example, passing `Source_` selects source-manager tests.

The executable is a native console program; use the executable path generated by the selected configuration and platform (for example, the `Debug` x64 output).

## Writing tests

Add test cases under `HolyTest/Sources/` and include the appropriate test harness and component headers. Keep tests independent, assert observable behavior with `CHECK`, and remove any temporary files created by a test. The current harness is intentionally small and does not provide fixtures, setup/teardown hooks, or command-line options beyond the optional substring filter.
